# Maison Samtpfote · öffentliche Demo

**[Website öffnen](https://mugennoyami.github.io/maison-samtpfote-demo/)**

Dieses Repository veröffentlicht ausschließlich die fertige Konzeptwebsite über GitHub Pages. Der eigentliche Projektquellcode bleibt im privaten Projekt.

- Vier Demoprodukte, Variantenwahl, lokaler Warenkorb und Demo-Checkout.
- Keine echten Bestellungen, Zahlungen oder E-Mails.
- Konzeptbilder sind KI-generiert; Preise und technische Angaben sind Beispiele.
- Formulareingaben werden nicht an einen Shop-Server übermittelt. Bitte nur Testdaten verwenden.

`site.zip` enthält den geprüften statischen Website-Export (HTML, CSS, JavaScript, Bilder und Schriftdateien). Der Pages-Workflow entpackt das Archiv und veröffentlicht den Inhalt. Aktualisierungen erfolgen durch einen neuen geprüften Export mit dem Basispfad `/maison-samtpfote-demo` und Austausch von `site.zip`.

Die Website ist öffentlich abrufbar, wird aber als Demo nicht zur Suchmaschinenindexierung freigegeben. Ein produktiver Shop erfordert bestätigte Produktangaben, Unternehmens-/Rechtstexte und serverseitige Shop- und Zahlungsdienste.
